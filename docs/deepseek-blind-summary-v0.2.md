# DeepSeek 匿名盲评本地汇总 v0.2

## 范围与入口

- 单轮盲评继续在 `/chart?ai_lab=1&specificity=100`，生成两份 DeepSeek 回答需要两次用户主动确认的调用。
- 多份数据汇总入口：`/lab/blind-results`。与单轮盲评界面相互链接。
- **纯本地**：仅在当前浏览器标签页的 React 状态处理 JSON，不上传文件、调用模型、创建数据库或 Redis。刷新页面后需重新导入。
- 以已导出的 `iziwei-blind-comparison-v1` JSON 为输入；可以多选文件、分次追加、重复导入自动去重。
- 每个文件不超过 512 KiB，一次最多 100 个文件，汇总最多 500 条不同记录；支持单条 JSON 或由此格式组成的 JSON 数组（若其中任意一条不合法则拒绝整个文件）。
- 导入时会校验：受支持的实验 schema、合成对照类型、明确度 0–100、提交时间、A/B 位置、用户原始选择、选择结果计算一致性、两份响应存在且属于同一模型。拒绝篡改、错误和超大文件。
- 解析后丢弃两份 AI 原文，只保存匿名编号、模型、日期、明确度、来源位置和选择等用于汇总的字段。仍然需要谨慎处理原始 JSON：原文可能包含 AI 生成的个人信息。

## 分组统计

| 指标 | 定义 |
| --- | --- |
| 总轮次 | 去重后的有效记录数量 |
| 选择真实盘 | 用户明确选了 A/B 中自己命盘对应的一份 |
| 选择合成盘 | 用户选了另一份 |
| 两份都像 / 两份都不像 / 无法判断 | 分别计数，不丢弃，也不混为正确或错误 |
| 全部轮次选真实盘比例 | 选择真实盘数量 / 所有有效轮次，包括无法明确选择 |
| 仅二选一时选真实盘比例 | 选择真实盘数量 /（选择真实盘 + 选择合成盘）；无明确选择时显示「—」 |
| 无明确选择占比 |（两份都像 + 两份都不像 + 无法判断）/ 所有轮次 |
| A/B 分配 | 真实盘随机分配到 A、B 各有多少轮 |
| 匿名样本编号 | 非空且不同的样本编号数量，供检查同一参与者可能重复 |
| 组间比较 | 按 specificity **精确数值**拆分，包括 0、50、100；混用模型会警告 |

支持下载只含**聚合数字**的 CSV。CSV 不写入原始 AI 文本、生辰和用户笔记。

## 解读限制

1. 这是探索性、弱盲评汇总，**不是命理预测准确率**，不展示统计显著性、p 值或“准确率”徽章。
2. 同一匿名编号可能重复测试，多次结果不是独立的人。没有编号的记录不能判断独立性。
3. 样本量较小时有警告；总数小于 20 轮、每组小于 10 轮会提示仅适合观察。阈值是演示提醒，不是科学样本量证明。
4. 同盘与合成盘的语言风格、命盘复杂度、生成波动、A/B 位置偏差、参与者自知出生信息等因素仍影响结果；必须保留负例、不确定例和未选择例。
5. 更严谨的下一阶段需要：预注册研究假设、同盘多次独立重复、隐匿分配、真实多参与者对照、随机化对照盘、客观可证伪陈述和专门的偏差审查。
6. 汇总页面 **不会发起新的 DeepSeek 请求**，不接 Qwen、Redis、云端用户库或付费系统。
