# 紫微研究 · 普通人解读 v2（2026-10-21）

## 为什么重写

之前“通俗解读”虽然不难懂字面，却仍然停留在“某颗星象征规划、责任、执行”，需要读者自行联想“这说的是我吗”。DeepSeek 系统提示还要求反复使用“传统上可理解为”，导致每段都像免责申明。目标客户未必懂紫微斗数，也未必受过高等教育；他们需要一句话就能联想到生活中的某个具体场面。

## 第一屏阅读标准

- **先说人怎么做事，而不是先说宫和星是什么。** 第一眼看到一条鲜明行为：“这事没人管时，你可能先接过来安排，但最后活儿常常都落到自己身上”。
- 每个专题只优先讲一个主导方向：一个日常场景、一种可能的动作、一项具体代价；不要列完整词典，不要同时写“既主动又谨慎、既独立又重感情”。
- 用常见生活环境：朋友吃饭选地方、同事互相推活儿、买东西反复比价、跟亲近的人闹别扭。不得假设用户一定已婚、上班、做生意、有孩子或挣多少钱。
- 文字短、直白、少术语。普通内容不解释“主星”“宫干”“飞化”；如需研究，在折叠的“为什么这样说”里看真实星曜与宫位。
- **敢说缺点，避免全篇奉承。** 结论要有明确的反面条件：如果用户总是做相反的事，说明这一条不匹配。
- **不得假装看过用户人生。** 盘面的星曜位置可核验，传统命盘对应的行为解释不能等同已验证的用户经历，也不能用确定语气推断历史事件、财富、婚姻、寿命、疾病、命运。
- 深层报告、专业依据、事实引用检查和盲评保留；新增普通用户入口不要求用户理解实验参数。

## 落地内容

1. 离线通俗报告用 14 颗主星的生活行为文案，按六个主题分别写出“表现 + 情景与代价”，不是简单替换几句同义词。空宫仍按已有程序结构使用对宫星曜，明示是参考不是原宫实际落入。
2. 默认命盘报告的“你做事的样子”占满一行，明显主句采用更易阅读的字号。技术依据放在可展开的详情里；导出 TXT 的正文同步更新。
3. 侧栏六个专题默认显示普通人能看懂的行为场景，不再直接显示一整段盘面结构分析；主动点星曜/四化等专业操作仍保留原专业依据。
4. DeepSeek plain 文案提示升级为 `lay-direct-v2`：专题提问先回答该专题，普通报告使用“你平时怎么做事／上班做事／跟人相处／花钱习惯／最容易吃亏的地方”。每节落在具体场景，不许复述术语词典、编造经历或给确定性的命运预测。
5. 仍保留实验“描述明确度 0–100”。0 现在表示不叠加额外实验指令，**不再意味着用户默认要看宽泛文案**。与此前版本相比实验基础提示词已经变化，过去的盲评 JSON 不能与这版直接比较。API 响应和新的导出带文案版本标识；旧版本按 untracked 处理。汇总会提醒混合版本。

## 验收范围与剩余问题

- 静态回归验证 14 主星存在不同故事模板、六专题文案不再是抽象词典、未知时辰继续提醒、技术依据仍可获取、格式化和下载不变。
- 自动回归只能保证有具体句式和按盘选用了对应模板，**不能证明真人看到后就觉得准**。必须用真实 DeepSeek API 响应和真人阅读理解访谈进一步验收：5 秒内是否看懂、是否能指出自己有没有做过、是否包含明显的错误、是否有另一种命盘也同样适用。
- 原生文案只按某宫优先主星选一条，深层星曜组合解释仍需持续提升，不可把“14 种模板”误称为真正个性化智能分析。
- 不增加 Qwen、Redis、会员或收费系统。
